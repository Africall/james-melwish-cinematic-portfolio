# James Melwish - CINEMATIC PORTFOLIO

Promised. Built. Proven.

The personal portfolio of James Melwish: Business Development & Product Manager at Spans Ventures Ltd (SpansCall) and lead engineer on the platform it runs on. Nairobi, Kenya.

A single cinematic page: a start gate that opens with sound, theatre-curtain reveal, video bookends, smooth inertial scrolling, film grain and a stacking deck of the Spans product line.

## Stack

React 19, Vite, Tailwind CSS 4, Framer Motion, Lenis.

## Develop

```bash
npm install
npm run dev
```

## Deploy

Pushing to `main` builds and publishes to GitHub Pages automatically via the workflow in `.github/workflows/deploy.yml`.
